# Script_Estandarizaci-n_shapefiles
Este script en Python automatiza la gestión geomática al escanear carpetas recursivamente para detectar Shapefiles y generar un diccionario de datos en Excel por cada capa. Extrae la longitud real de texto directamente del archivo nativo .dbf, mapea geometrías al español y aplica un diseño visual corporativo y limpio de forma automatizada.
